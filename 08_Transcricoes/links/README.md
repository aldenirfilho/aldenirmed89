# Links — Transcrições

Adicione links externos, páginas HTML interativas, vídeos, aulas ou notas online em `links.json`.

Exemplo:

```json
[
  {
    "title": "Nome do material",
    "url": "https://exemplo.com/transcricao.html",
    "format": "html",
    "description": "Descrição objetiva do conteúdo.",
    "tags": ["transcricao", "aula", "html"]
  }
]
```

Depois rode `bash scan_inbox.sh` na pasta do módulo.
