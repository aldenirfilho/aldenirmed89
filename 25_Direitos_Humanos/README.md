# Direitos Humanos — guia de reconhecimento

Site estático em HTML, CSS e JavaScript, criado a partir da conversa sobre violações de direitos humanos, crimes contra a humanidade, crimes de guerra e genocídio.

Preparado como seção educacional independente do portal AldenirMed89, com navegação de ida e volta para a página principal.

## Conteúdo

- distinções jurídicas essenciais;
- 12 exemplos de condutas graves;
- filtros por contexto e pesquisa textual;
- sete contextos internacionais documentados;
- critérios para leitura responsável de denúncias;
- links para fontes primárias.

## Executar localmente

Abra `index.html` diretamente ou use um servidor estático:

```bash
python3 -m http.server 8080
```

Depois acesse `http://localhost:8080`.

## Privacidade e dependências

- nenhuma dependência externa;
- nenhuma coleta de dados;
- nenhuma chamada de rede durante o uso, exceto quando o visitante abre voluntariamente um link de fonte;
- funciona offline.

## Nota editorial

Material educacional consolidado em 3 de novembro de 2026. Situações em curso podem mudar. Alegação, investigação, mandado, decisão de comissão e condenação judicial são etapas diferentes.
