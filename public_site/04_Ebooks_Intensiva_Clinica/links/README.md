# Links — Ebooks Intensiva & Clínica Médica Interna

Adicione links externos, páginas HTML interativas, repositórios ou materiais online em `links.json`.

Exemplo:

```json
[
  {
    "title": "Nome do material",
    "url": "https://exemplo.com/material.html",
    "format": "html",
    "description": "Descrição objetiva do conteúdo.",
    "tags": ["ebook", "uti", "html"]
  }
]
```

Depois rode `bash scan_inbox.sh` na pasta do módulo.
