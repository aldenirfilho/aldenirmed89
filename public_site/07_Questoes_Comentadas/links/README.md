# Links — Questões Comentadas

Adicione links externos, páginas HTML interativas, bancos online, simulados ou materiais de estudo em `links.json`.

Exemplo:

```json
[
  {
    "title": "Nome do material",
    "url": "https://exemplo.com/questoes.html",
    "format": "html",
    "description": "Descrição objetiva do conteúdo.",
    "tags": ["questoes", "temi", "html"]
  }
]
```

Depois rode `bash scan_inbox.sh` na pasta do módulo.
