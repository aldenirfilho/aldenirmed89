#M Compensação esperada na acidose metabólica
IMG gaso | pH=7,28 ; PaCO2=26 ; HCO3=12 ; Na=140 ; Cl=102 ; Lac=7,8 ; Alb=4,0
S: Homem de 60 anos em choque séptico tem a gasometria da figura. Aplicando a fórmula de Winter, como classificar o distúrbio?
+ Acidose metabólica com ânion gap elevado e compensação respiratória adequada :: PaCO2 esperada = 1,5 × 12 + 8 = 26 ± 2; AG = 140 − (102 + 12) = 26.
- Acidose metabólica com acidose respiratória associada :: A PaCO2 está dentro do esperado.
- Acidose metabólica com alcalose respiratória associada :: A PaCO2 não está abaixo de 24.
- Acidose metabólica hiperclorêmica pura :: O AG está elevado.
- Distúrbio respiratório primário :: O HCO3 baixo com pH ácido indica distúrbio metabólico primário.
K: Winter: PaCO2 esperada = 1,5 × HCO3 + 8 (± 2). PaCO2 acima → acidose respiratória associada; abaixo → alcalose respiratória associada.

#M Delta-delta puro
IMG gaso | pH=7,28 ; PaCO2=26 ; HCO3=12 ; Na=140 ; Cl=102 ; Alb=4,0 ; Glic=480
S: Paciente com cetoacidose tem a gasometria da figura. Calculando a relação delta-delta, qual a interpretação?
+ Acidose metabólica de AG elevado pura (ΔAG/ΔHCO3 ≈ 1,2) :: ΔAG = 26 − 12 = 14; ΔHCO3 = 24 − 12 = 12.
- Acidose de AG elevado com alcalose metabólica associada :: Exigiria relação > 2.
- Acidose de AG elevado com acidose hiperclorêmica associada :: Exigiria relação < 1.
- Acidose respiratória :: Distúrbio primário metabólico.
- Alcalose metabólica :: pH ácido e HCO3 baixo.
K: Delta-delta = ΔAG/ΔHCO3: < 1 → acidose não-AG associada; 1–2 → AG pura; > 2 → alcalose metabólica associada (ou acidose respiratória crônica).

#M Correção do ânion gap pela albumina

#M Cetoacidose diabética | DKA24
