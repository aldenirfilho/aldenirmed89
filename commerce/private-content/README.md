# Conteúdo privado — não incluir neste repositório público

O serviço só entrega arquivos que estejam **fora de todo o checkout**, em volume privado montado, com manifesto explícito. Não copie artigos/PDFs, dados de pacientes nem conteúdo de terceiros para cá.

Exemplo de manifesto no volume externo (exemplo não habilitado):

```json
[
  {
    "slug": "primeiro-microestudo",
    "title": "Primeiro microestudo autoral",
    "feature": "microestudos",
    "file": "primeiro-microestudo.md",
    "reviewed": false,
    "rightsCleared": false
  }
]
```

Mudar flags exige revisão real do conteúdo e direitos de comercialização. Um arquivo não implementa sozinho histórico, simulados ou revisão personalizada. Essas funções precisam de implementação e homologação antes de a oferta ser ativada. O acervo público existente segue público; a proteção deste serviço não retroage para ele.
