# **02 · AVALIAÇÃO INICIAL & EMERGÊNCIA**

## **🚨 Os 2 Maiores Inimigos — Lesão Secundária**

|   |   |   |   |   |
|---|---|---|---|---|
|**Agressão**|**Definição**|**Prevalência**|**Risco Relativo**|**Meta**|
|HIPOTENSÃO|PAS < 90 mmHg|30% dos pacientes|RC 2,67 de desfecho ruim|PAS ≥ 100–110 mmHg|
|HIPÓXIA|PaO₂ < 60 mmHg|50% dos pacientes|RC 2,14 de desfecho ruim|PaO₂ 80–120 mmHg|

|   |
|---|
|**🔥 DADO CRÍTICO para a TEMI**<br><br>PAS < 90 mmHg → risco de morte TRIPLICADO<br><br>PAS < 100 mmHg → risco de morte DOBRADO<br><br>PAS < 120 mmHg → risco 1,5× maior (análise de 5.057 pacientes — registro europeu)|

## **🆘 Protocolo de Herniação Cerebral Iminente**

**Sinais Clínicos de Alerta:**

- Tríade de Cushing: Hipertensão + Bradicardia + Respiração irregular
- Pupilas fixas e dilatadas (uni ou bilateral)
- Postura de decorticação (flexão) ou descerebração (extensão)
- Depressão respiratória

**Protocolo Imediato Passo a Passo:**

1. Intubação orotraqueal (se ainda não realizada)
2. Cabeceira 30–45° + cabeça em posição neutra
3. Hiperventilação BREVE: PaCO₂ 30–35 mmHg / EtCO₂ 25–30 mmHg (temporária!)
4. Agente osmótico em bolus: NaCl 23,4% 30–60mL em 10min OU Manitol 1–1,5 g/kg
5. Manter PAM 80–100 mmHg (volemia + vasopressor se necessário)
6. TC de crânio + avaliação neurocirúrgica IMEDIATA

|   |
|---|
|**❌ HIPERVENTILAÇÃO PROLONGADA — PROIBIDA**<br><br>Vasoconstrição cerebral → ↓ FSC → ISQUEMIA SECUNDÁRIA<br><br>Aumenta lactato e glutamato extracelulares<br><br>Estudo randomizado: PaCO₂ ≤ 25 mmHg por 5 dias = PIOR desfecho<br><br>Usar APENAS como ponte temporária na herniação iminente!|

# **03 · UTI — MANEJO HEMODINÂMICO & VENTILAÇÃO**

## **💧 Fluidos — Regra de Ouro**

|   |   |   |
|---|---|---|
|**Fluido**|**Recomendação**|**Motivo**|
|SF 0,9% (Soro Fisiológico)|✅ PADRÃO — manter euvolemia|Isotônico, sem risco de edema cerebral|
|Albumina|❌ CONTRAINDICADA|SAFE Trial: mortalidade 42% vs 22% no TCE!|
|Ringer Lactato / Plasmalyte|⚠️ EVITAR|Relativamente hipotônico → piora edema cerebral|
|Solução Salina Hipertônica|✅ Para controle de PIC|Agente osmótico — ver seção PIC|

## **🫁 Ventilação Mecânica — Metas**

|   |   |   |
|---|---|---|
|**Parâmetro**|**Meta**|**Observação**|
|PaO₂|80–120 mmHg (mínimo > 60)|Hipóxia = lesão secundária grave|
|PaCO₂|35–45 mmHg (normocarbia)|Hipercapnia → ↑ PIC; Hipocapnia → isquemia|
|SpO₂|≥ 90–93%|Meta de segurança mínima|
|PEEP|Até 15–20 cmH₂O (SDRA)|Sem efeito consistente na PIC; melhora PbtO₂|
|EtCO₂|Monitorar continuamente|Capnografia em todos os intubados com TCE|
|Traqueostomia|Preferir ≤ 7 dias|↓ 4 dias VM · ↓ 6 dias UTI · ↓ PAV|

|   |
|---|
|**💉 Profilaxia PAV — Ceftriaxona (Grau 2B)**<br><br>2g IV dose única em até 12h após intubação<br><br>Reduz PAV em 7 dias: 14% vs 32%<br><br>Reduz mortalidade em 28 dias: 15% vs 25%|

## **🌡️ Controle de Temperatura**

- Paracetamol 1g enteral 6–8/8h em TODOS com T > 37°C
- Resfriamento de superfície se PIC elevada refratária
- Hipotermia terapêutica induzida: NÃO melhora desfechos — apenas em ensaios clínicos
- Febre → ↑ demanda metabólica → ↑ FSC → ↑ PIC

## **🩸 Transfusão de Hemácias — Metas**

|   |   |   |
|---|---|---|
|**Situação**|**Meta de Hb**|**Evidência**|
|Geral (maioria dos pacientes)|8–9 g/dL|HEMOTION / TRAIN|
|Risco de isquemia cerebral (PbtO₂ < 20, PIC refratária)|≥ 9 g/dL|Estudo PbtO₂|
|Sangramento ativo|Transfundir conforme clínica|Protocolo trauma|

|   |
|---|
|**⚠️ TRAIN Trial — Importante para TEMI**<br><br>Limiar restritivo Hb 7 g/dL versus liberal Hb 9 g/dL:<br><br>Desfecho neurológico ruim: 72,6% (restritivo) vs 62,6% (liberal) — RR 0,86<br><br>Eventos isquêmicos cerebrais: 13,5% vs 8,8% (RR 0,65) — MAIS isquemia com Hb baixa!|

## **🧪 Controle Glicêmico & Eletrólitos**

- Meta glicemia: 140–180 mg/dL — evitar extremos
- NÃO usar insulinoterapia intensiva (80–110 mg/dL) → risco de hipoglicemia cerebral
- Hiperglicemia E hipoglicemia → pior prognóstico neurológico
- Eletrólitos seriados a cada 4–6h (Na⁺, K⁺, Cl⁻, osmolalidade)

## **🧠 Anticonvulsivantes — Profilaxia 7 Dias**

**Indicações:**

- Contusão cortical visível na TC
- HSD, HED ou HIC
- Fratura craniana com afundamento
- Ferimento penetrante craniano
- Convulsão nas primeiras 24h
- GCS < 11

|   |   |   |
|---|---|---|
|**Droga**|**Dose**|**Recomendação**|
|Levetiracetam (preferido)|Ataque: 20 mg/kg IV em 60min \| Manutenção: 1000mg IV 12/12h|✅ Melhor desfecho cognitivo a longo prazo|
|Fenitoína (alternativa)|Consultar protocolo institucional|⚠️ Pior desfecho cognitivo — associação adversa comprovada|

- Duração: 7 dias — suspender sem desmame se sem crise
- EEG contínuo: 15–25% dos pacientes têm crises não convulsivas ocultas!
- Crises eletrográficas silenciosas: tratar se GCS baixo desproporcional à lesão

## **🩹 Profilaxia TEV**

- Compressão pneumática intermitente: desde a admissão — Grau 1A
- Heparina não fracionada 5000 UI 3x/dia OU Enoxaparina 40mg/dia
- Iniciar farmacológico: 24h após estabilidade confirmada por imagem
- Meta: Plaquetas > 75.000/µL | INR < 1,4

# **04 · CONTROLE DA PRESSÃO INTRACRANIANA**

|   |
|---|
|**🎯 Metas Primárias — BTF 2016**<br><br>PIC ≤ 22 mmHg<br><br>PPC (PAM − PIC) = 60–70 mmHg<br><br>Iniciar monitoração: TCE grave (GCS < 9) + TC anormal com efeito de massa|

## **📈 Algoritmo Escalonado — Manejo da PIC**

|   |   |   |
|---|---|---|
|**Tier**|**Intervenção**|**Detalhes**|
|🟢 BASE|Posicionamento|Cabeceira 30° + pescoço neutro + afrouxar colar cervical|
|🔵 TIER 1|DVE + Drenagem LCR|Drenagem contínua a 20cm acima do trago · GCS < 6 nas 1as 12h: contínua obrigatória|
|🔵 TIER 1|Sedoanalgesia|Propofol + Fentanil · RASS 0 a –2 se PIC OK · RASS –4/–5 se refratária|
|🟡 TIER 2|Terapia Osmótica|NaCl 3% 0,1–1 mL/kg/h ou bolus NaCl 23,4% 30mL em 10min OU Manitol 0,25–0,5 g/kg|
|🔴 TIER 3|Craniectomia Descompressiva|PIC > 22 por > 1–12h refratária · mínimo ≥ 12×15cm ou 15cm diâmetro|
|⚫ TIER 4|Coma Barbitúrico|Pentobarbital 5–20 mg/kg + 1–4 mg/kg/h · EEG: burst-suppression · SE craniectomia impossível|

## **💧 NaCl 23,4% vs Manitol — Comparação**

|   |   |   |
|---|---|---|
|**Critério**|**NaCl 23,4%**|**Manitol**|
|Dose bolus|30–60 mL em 10 min|1–1,5 g/kg IV|
|Efeito volêmico|Expande volume (não depleta)|Diurético osmótico (depleta volume)|
|Coeficiente reflexão|1,0 (ideal)|0,9 (menor)|
|Risco extravasamento|Menor|Maior (ruptura BHE)|
|Preferir em|Trauma, hipovolemia, hemorragia ativa|Alternativa aceitável|
|Monitorar|Na⁺, Cl⁻ seriados|Osmolalidade < 320 mOsm/L|
|Acesso venoso|CVC preferencial (pode ser AVP em emergência)|Periférico aceitável|

|   |
|---|
|**⚠️ Descontinuação Gradual dos Osmóticos**<br><br>Efeito osmótico diminui em 24h (osmoles cerebrais compensatórios)<br><br>Suspensão abrupta → inversão gradiente → EDEMA CEREBRAL DE REBOTE<br><br>Reduzir gradualmente após uso prolongado|

## **🔪 Craniectomia Descompressiva — Evidências**

|   |   |   |   |
|---|---|---|---|
|**Ensaio**|**N**|**Critério**|**Resultado**|
|DECRA (2011)|155|TCE difuso grave, PIC > 20 por 15min|Cirurgia: ↓ PIC + ↓ UTI MAS pior E-GOS em 6m (limitações metodológicas)|
|RESCUEicp (2016)|408|PIC > 25 por 1–12h refratária|Cirurgia: mortalidade 27% vs 49% \| Vegetativo: 8,5% vs 2,1% \| 1 ano: 45% vs 32% favorável|

|   |
|---|
|**📌 Técnica Cirúrgica — Pontos Críticos**<br><br>Tamanho: ≥ 12×15 cm ou 15 cm diâmetro (craniectomia pequena = ineficaz + risco infarto venoso)<br><br>Durotomia ampla: maior parte da redução da PIC vem da abertura da dura-máter<br><br>Descompressão adequada da fossa média (prevenir herniação uncal mesmo com PIC normal)<br><br>Hemicraniectomia para lesões unilaterais; bifrontal extensa para difusas|

## **🔬 Coma Barbitúrico — Pentobarbital**

- Indicação: PIC refratária quando Tier 1–2 falhou E craniectomia não é viável
- Ataque: 5–20 mg/kg IV → Manutenção: 1–4 mg/kg/h
- Monitorar EEG continuamente → alvo: padrão burst-suppression
- Efeitos adversos: hipotensão (vasopressor!), íleo, pneumonia (PAV)
- CUIDADO: acidose metabólica por toxicidade do propilenoglicol
- Atrasa exame neurológico e determinação de morte encefálica (longa meia-vida)

## **📡 Monitoramento da PIC — DVE vs Intraparenquimatoso**

|   |   |   |
|---|---|---|
|**Método**|**Vantagem**|**Desvantagem**|
|DVE (Ventricular)|Padrão ouro · diagnóstico + terapêutico · drenagem LCR|Risco maior de hemorragia e infecção · difícil em ventrículos pequenos|
|Intraparenquimatoso|Mais fácil de inserir · menor risco|Sem possibilidade de drenagem LCR · PIC contínua apenas quando DVE fechado|
|DBNO (ultrassom)|Não invasivo|Ainda EXPERIMENTAL — não guia tratamento|

# **05 · FARMACOLOGIA CRÍTICA NO TCE**

## **😴 Sedoanalgesia — Propofol + Fentanil**

|   |   |   |   |   |
|---|---|---|---|---|
|**Fármaco**|**Dose UTI**|**Mecanismo**|**Efeito Cerebral**|**Cuidado Principal**|
|Propofol (1ª linha)|5–50 mcg/kg/min IV|Agonista GABA-A|↓ CMO₂ ↓ FSC ↓ PIC|PRIS: acidose + rabdomiólise (doses altas prolongadas)|
|Fentanil|0,7–10 mcg/kg/h IV|Agonista opioide|Analgesia sem ↑ PIC se normoventilado|Acúmulo em uso prolongado; rigidez torácica em bolus rápido|
|Midazolam (alternativa)|0,02–0,1 mg/kg/h IV|Agonista GABA-A|Amnésico + sedativo|Acúmulo + delirium; evitar como 1ª linha|
|Dexmedetomidina|0,2–1,5 mcg/kg/h|Agonista alfa-2 central|Sedação sem depressão respiratória|Bradicardia + hipotensão|

|   |
|---|
|**🚨 Síndrome de Infusão do Propofol (PRIS)**<br><br>Tríade: Acidose metabólica grave + Rabdomiólise + Hipercalemia<br><br>Pode evoluir para: Insuficiência renal aguda + Colapso cardiovascular<br><br>Risco com: doses > 5 mg/kg/h por > 48h<br><br>Prevenção: limitar dose + monitorar CPK, gasometria e eletrólitos|

## **💧 Terapia Osmótica — Protocolos**

**NaCl 3% (manutenção contínua):**

- Infusão: 0,1–1 mL/kg/hora IV (CVC preferencial)
- Meta Na⁺: 145–155 mEq/L
- Monitorar Na⁺, Cl⁻ e balanço hídrico a cada 4–6h

**NaCl 23,4% (bolus — crise aguda):**

- 30 mL IV em 10 minutos (pode administrar em AVP em emergência)
- Preferido em trauma, hipovolemia, instabilidade hemodinâmica
- Atenção: hipotensão transitória com infusão muito rápida

**Manitol (alternativa):**

- 0,25–0,5 g/kg IV a cada 4–6 horas conforme PIC
- Osmolalidade sérica alvo: < 320 mOsm/L
- Função renal diariamente (diurético osmótico)
- Evitar em hipovolemia/instabilidade hemodinâmica

# **10 · NERD ZONE — Fisiopatologia & Curiosidades**

## **🧬 Doutrina de Monro-Kellie**

A cavidade craniana tem volume fixo: Parênquima + LCR + Sangue = constante.

- Compensação 1: ↓ LCR (deslocamento para o espaço lombar)
- Compensação 2: ↓ volume venoso cerebral
- Quando AMBAS se esgotam → PIC sobe de forma EXPONENCIAL (curva de complacência intracraniana)
- Craniectomia 'quebra' a doutrina ao criar um novo compartimento de expansão
- Ventrículos em fenda = compensação máxima atingida = DVE tecnicamente muito difícil

## **🌊 Autorregulação Cerebral e o PRx**

- Normal: FSC estável entre PAM 50–150 mmHg (plato de autorregulação)
- ~33% dos TCE graves PERDEM a autorregulação
- 'Pacientes passivos à pressão': ↑ PAM → ↑ volume sanguíneo cerebral → ↑ PIC
- PRx próximo de 0 = autorregulação preservada
- PRx próximo de +1 = autorregulação praticamente ausente
- PPC ótima = ponto mais baixo da curva U de PRx × PPC (individualiza o alvo)
- Hipertensão com autorregulação comprometida AGRAVA edema cerebral!
