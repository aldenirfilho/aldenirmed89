# 📥 Inbox — Depósito Geral da Biblioteca IA

Jogue aqui **TODOS** os documentos novos da Biblioteca IA de uma vez.

## Formatos aceitos
- `.docx` / `.doc` — Documentos Word produzidos por IA / curadoria própria
- `.pdf` — Artigos científicos, guidelines, PDFs e referências
- `.xls` / `.xlsx` — Planilhas
- `.md` / `.markdown` — Markdown
- `.csv` / `.tsv` — Dados, tabelas e materiais exportáveis
- `.ppt` / `.pptx` — Apresentações e aulas
- `.txt` — Textos simples
- `.apkg` / arquivos com "anki" ou "flashcard" no nome — materiais para flashcards
- `.html` — Páginas interativas

## Fluxo
1. Cole todos os arquivos nesta pasta
2. Rode: `cd 02_Biblioteca_IA_Engine && bash scan_inbox.sh`
3. Faça commit + push
4. Abra a Biblioteca no navegador
5. Use a busca por tema, formato e origem
6. Clique em **👁️ Ver** para visualizar ou **⬇️ Baixar** para baixar
7. Clique em **📂 Classificar** para revisar tema/origem/tags

## ⚠️ Segurança
- NÃO suba documentos com dados de pacientes identificáveis
- NÃO suba prontuários, prescrições reais ou exames com nome
