# 🧯 Checklist prático ABCDE para estação TEMI

## A — Airway

- [ ] Fala? ronco? estridor? vômito? sangue?
- [ ] Proteção cervical se trauma.
- [ ] Aspirar, cânula, pré-oxigenar.
- [ ] Plano de via aérea difícil.

## B — Breathing

- [ ] SpO₂, FR, esforço, ausculta, expansibilidade.
- [ ] Gasometria se muda conduta.
- [ ] Oxigênio/CNAF/VMNI/IOT conforme gravidade.
- [ ] Pneumotórax hipertensivo? tratar sem esperar RX.

## C — Circulation

- [ ] Pulso, PA, perfusão, TEC, pele, diurese, lactato.
- [ ] Dois acessos/central se necessário.
- [ ] Fluido se responsivo e tolerante.
- [ ] Vasopressor precoce se hipotensão ameaçadora.
- [ ] ECG/POCUS/foco de sangramento.

## D — Disability

- [ ] Glasgow/RASS/pupilas/glicemia/temperatura.
- [ ] Convulsão, HIC, toxinas, sepse, hipoxemia.

## E — Exposure

- [ ] Expor e procurar foco: pele, cateter, abdome, trauma.
- [ ] Prevenir hipotermia.
- [ ] Comunicação e plano.
