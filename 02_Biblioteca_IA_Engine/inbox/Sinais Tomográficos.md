# 🧠 7 SINAIS DE TC SIMPLES PREDITORES DE EXPANSÃO DE HEMATOMA INTRACEREBRAL
### *Guia Prático para Plantonista e Intensivista*

---

| Letra | Sinal | Palavra-chave |

| **B** | **B**lend sign | Mistura |
| **E** | **E**xtensão intraventricular | IVH |
| **B** | **B**lack hole | Buraco negro |

> 💡 *Dica: "BEBÊ com S.H.I.E." = Hematoma que "cresce" (expande) como um bebê*

---

## 📋 DESCRIÇÃO PRÁTICA DOS 7 SINAIS

### 1️⃣ **BLEND SIGN** (Sinal da Mistura)
| Característica | Descrição |
|---------------|-----------|
| 🔍 **Como identificar** | Área hipodensa adjacente a área hiperdensa com margem bem definida e ≥18 HU de diferença [[36]] |
| 🎯 **Significado** | Sangue fresco não coagulado misturando-se ao coágulo formado = sangramento ativo |
| 📊 **Acurácia** | Sensibilidade ~39% | Especificidade ~95% [[8]] |
| ⚡ **Dica prática** | Procure na periferia do hematoma: "metade clara, metade escura, cortadas ao meio" |

### 2️⃣ **BLACK HOLE SIGN** (Sinal do Buraco Negro)
| Característica | Descrição |
|---------------|-----------|
| 🔍 **Como identificar** | Área hipodensa arredondada/oval/linear DENTRO do hematoma hiperdenso, com borda nítida e ≥28 HU de diferença [[40]] |
| 🎯 **Significado** | Pool de sangue não coagulado encapsulado = risco de expansão [[32]] |
| 📊 **Acurácia** | Sensibilidade ~32% | Especificidade ~94% [[18]] |
| ⚡ **Dica prática** | "Olho dentro do hematoma" - parece um buraco escuro no meio da lesão brilhante |

### 3️⃣ **SWIRL SIGN** (Sinal do Redemoinho)
| Característica | Descrição |
|---------------|-----------|
| 🔍 **Como identificar** | Área iso/hipodensa em padrão linear, circular ou irregular DENTRO do hematoma, visível em ≥2 cortes consecutivos de 5mm [[15]] |
| 🎯 **Significado** | Extravasamento agudo de sangue não coagulado = sangramento em atividade [[6]] |
| 📊 **Acurácia** | Sensibilidade ~45% | Especificidade ~79% (meta-análise) [[7]] |
| ⚡ **Dica prática** | "Redemoinho de café" - procure padrões espiralados ou estriados dentro do coágulo |

### 4️⃣ **SATELLITE SIGN** (Sinal do Satélite)
| Característica | Descrição |
|---------------|-----------|
| 🔍 **Como identificar** | Pequenos focos hiperdensos (<1cm) SEPARADOS do hematoma principal, na periferia [[13]] |
| 🎯 **Significado** | Múltiplos focos de sangramento = instabilidade hemostática |
| 📊 **Acurácia** | Sensibilidade ~25-40% | Especificidade ~85-95% [[13]] |
| ⚡ **Dica prática** | "Planetas ao redor do sol" - pequenos pontos brilhantes orbitando o hematoma principal |

### 5️⃣ **FLUID LEVEL SIGN** (Sinal do Nível Hidroaéreo)
| Característica | Descrição |
|---------------|-----------|
| 🔍 **Como identificar** | Linha horizontal nítida separando componente hiperdenso (inferior) de hipodenso (superior) dentro do hematoma [[13]] |
| 🎯 **Significado** | Sedimentação de elementos sanguíneos = coagulação incompleta e sangramento ativo |
| 📊 **Acurácia** | Sensibilidade ~15-30% | Especificidade ~90-98% [[13]] |
| ⚡ **Dica prática** | "Copo de suco com polpa" - nível horizontal como em líquido em repouso |

### 6️⃣ **HETEROGENEIDADE DE DENSIDADE**
| Característica | Descrição |
|---------------|-----------|
| 🔍 **Como identificar** | Variação de atenuação >18 HU dentro do hematoma, sem padrão específico de blend/black hole [[17]] |
| 🎯 **Significado** | Mistura de sangue em diferentes estágios de coagulação = processo dinâmico |
| 📊 **Acurácia** | Sensibilidade ~60-80% | Especificidade ~50-70% [[8]] |
| ⚡ **Dica prática** | "Mármore" - hematoma com "manchas" de diferentes tons de cinza |

### 7️⃣ **EXTENSÃO INTRAVENTRICULAR (IVH)**
| Característica | Descrição |
|---------------|-----------|
| 🔍 **Como identificar** | Sangue hiperdenso dentro dos ventrículos cerebrais, conectado ou não ao hematoma parenquimatoso [[13]] |
| 🎯 **Significado** | Ruptura da barreira ependimária = hematoma de maior energia/pressão |
| 📊 **Acurácia** | Sensibilidade ~30-50% | Especificidade ~70-85% para expansão [[13]] |
| ⚡ **Dica prática** | "Ventrículo pintado de branco" - procure sangue nos cornos temporais/occipitais |

---

## 🧩 MNEMÔNICO DE RECONHECIMENTO RÁPIDO: **"3D + 4P"**

### **3D** - Características de Densidade
```
Diferença de HU (≥18-28)
Densidade mista (hipo + hiper)
Delimitação nítida (borda definida)
```

### **4P** - Características de Padrão
```
Periferia (blend, satellite)
Profundidade (black hole, swirl)
Plano horizontal (fluid level)
Parenquima-ventrículo (IVH)
```

## 📊 TABELA RESUMO PARA DECISÃO CLÍNICA

| Sinal | Sensibilidade | Especificidade | VP+ | Ação Imediata |
|-------|--------------|---------------|-----|--------------|
| Blend | ~39% | ~95% | Alta | Controle rigoroso de PA |
| Black Hole | ~32% | ~94% | Alta | Reavaliar em 1-2h |
| Swirl | ~45% | ~79% | Moderada | Considerar CTA |
| Satellite | ~25-40% | ~85-95% | Alta | Monitorização intensiva |
| Fluid Level | ~15-30% | ~90-98% | Muito Alta | Urgência em estabilização |
| Heterogeneidade | ~60-80% | ~50-70% | Baixa | Correlacionar com outros sinais |
| IVH | ~30-50% | ~70-85% | Moderada | Avaliar necessidade de DVE |

> 📌 **Regra prática**: ≥2 sinais positivos = risco MUITO alto de expansão (OR 4-8x) [[8]]

## 🔄 ALGORITMO PRÁTICO NO PLANTÃO

```
TC de entrada com HIC → Procurar os 7 sinais
│
├─ 0 sinais → Risco baixo → Monitorar a cada 6h
│
├─ 1 sinal → Risco moderado → 
│   • Controle de PA <140 mmHg
│   • Reavaliar TC em 3-4h se deterioração
│
└─ ≥2 sinais → Risco ALTO → 
    • UTI/Unidade de AVC
    • PA alvo 130-139 mmHg [[14]]
    • Considerar CTA para spot sign
    • Reavaliar TC em 1-2h
    • Discutir reversão de anticoagulantes se aplicável
```

## 🧠 MNEMÔNICO DE CONDUTA: **"PAUSA RÁPIDA"**

| Letra | Conduta | Justificativa |
|-------|---------|--------------|
| **P** | **P**A controlada (130-139 mmHg) | Reduz expansão em 30-50% [[14]] |
| **A** | **A**nticoagulante revertido (se aplicável) | OAC aumenta risco 6x [[26]] |
| **U** | **U**rgência na reavaliação por imagem | Expansão ocorre em 1-3h [[5]] |
| **S** | **S**inais combinados = maior risco | 2+ sinais = OR 4-8x [[8]] |
| **A** | **A**lerta para deterioração neurológica | Expansão = pior prognóstico [[3]] |
| **R** | **R**astrear causa (CTA se disponível) | Spot sign = alvo terapêutico [[8]] |
| **Á** | **Á**lcool/antiagregante: suspender | APT aumenta risco de expansão [[24]] |
| **P** | **P**lanear seguimento (TC controle) | Definir janela de reavaliação |
| **I** | **I**nternar em unidade adequada | Monitorização contínua |
| **D** | **D**ocumentar sinais no laudo | Comunicação multidisciplinar |
| **A** | **A**valiar critérios para intervenção | Cirurgia/DVE se indicado |

## ⚠️ LIMITAÇÕES IMPORTANTES

1. **Baixa sensibilidade individual**: Nenhum sinal isolado "afasta" expansão [[42]]
2. **Dependência do tempo**: Sinais mais visíveis nas primeiras 3h [[5]]
3. **Variabilidade interobservador**: Treinamento melhora concordância (κ 0.53-0.64) [[8]]
4. **Volume basal é o melhor preditor isolado**: >30 mL = alto risco independentemente dos sinais [[8]]
