## 🎯 INDICAÇÕES PRINCIPAIS (Mnemônico: **IN-UTI**)

```
I - Infecção respiratória não esclarecida
N - Neoplasia suspeita / Hemoptise
U - Urgência: corpo estranho / obstrução aguda
T - Toalete brônquica: atelectasia refratária
I - Intubação difícil / troca de cânula
```

## ⚠️ CONTRAINDICAÇÕES (Mnemônico: **NÃO-FAÇA**)

```
N - Não consentimento informado (ABSOLUTA)
A - Arritmia maligna não controlada
O - Oxigenação impossível (hipoxemia refratária)

F - Falência hemodinâmica instável
A - Alteração coagulativa grave não corrigível
Ç - Choque cardiogênico/hipovolêmico não estabilizado
A - Angina instável / IAM < 4 semanas
```

### Classificação Prática:

| Tipo            | Contraindicação                                                  | Manejo                       |
| --------------- | ---------------------------------------------------------------- | ---------------------------- |
| **ABSOLUTA** 🚫 | Consentimento ausente                                            | Adiar procedimento           |
|                 | Hipoxemia refratária (SpO₂ <85% apesar de FiO₂ 100%)             | Otimizar ventilação primeiro |
|                 | Sangramento grave não corrigível (plaquetas <20.000 ou INR >2,5) | Corrigir coagulopatia        |
|                 | Arritmia ventricular maligna                                     | Estabilizar ritmo cardíaco   |
| **RELATIVA** ⚠️ | IAM recente (4-6 semanas)                                        | Avaliar risco-benefício      |
|                 | Hipertensão arterial não controlada                              | Controlar PA antes           |
|                 | Asma grave/estado de mal asmático                                | Broncodilatação prévia       |
|                 | Uremia grave (risco de sangramento)                              | Considerar diálise prévia    |

> 📚 **Fonte**: American Thoracic Society define apenas 4 contraindicações absolutas [[3]] DOI: 10.1164/rccm.163.3.347

## 🛡️ CUIDADOS PRÉ-PROCEDIMENTO (Mnemônico: **PREP-AR**)

```
P - Preparo do paciente: jejum, consentimento, avaliação
R - Revisão de medicações: anticoagulantes, antiagregantes
E - Equipamento: calibre do broncoscópio vs. cânula (ver tabela abaixo)
P - Pré-oxigenação: FiO₂ 100% por 5-10 min

A - Acesso venoso seguro e monitorização
R - Recursos de emergência disponíveis (carro de parada, tubo de tórax)
```

### 🔧 Ajustes no Paciente Ventilado:

| Parâmetro | Ajuste Recomendado | Justificativa |
|-----------|-------------------|---------------|
| **FiO₂** | ↑ para 100% 5-10 min antes | Prevenir dessaturação [[12]] |
| **Alarme de pressão** | ↑ limite para evitar disparos | Broncoscópio ocupa 30-81% da área da cânula [[4]] |
| **Modo ventilatório** | Manter volume corrente ou pressão controlada | Evitar auto-PEEP excessivo [[12]] |
| **Sedação** | Titular cuidadosamente (propofol/remifentanil) | Minimizar depressão respiratória [[4]] |

### 📏 Relação Cânula/Broncoscópio (CRÍTICO!):

```
Regra prática: Diâmetro interno da cânula ≥ diâmetro externo do broncoscópio + 2 mm

Exemplo:
• Cânula 8,0 mm → Broncoscópio ≤ 5,8 mm (adulto padrão: 4,9-5,9 mm) ✓
• Cânula 7,0 mm → Broncoscópio ≤ 4,9 mm (usar pediátrico se necessário) ⚠️
• Cânula < 7,0 mm → Risco alto de obstrução → considerar alternativa ❌
```
[[4]] DOI: 10.31744/einstein_journal/2018AO4380

## 🚨 COMPLICAÇÕES E MANEJO (Mnemônico: **HIPO-BRA-SP**)

```
H - Hipoxemia (mais comum: 3-65%)
I - Instabilidade hemodinâmica
P - Pneumotórax (0,4-23,6%)

O - Obstrução de via aérea/broncoespasmo

B - Sangramento (0,19-32,4%)
R - Arritmias (1,5-5,7%)
A - Aspiração/infecção cruzada

S - Sedação excessiva
P - Piora da ventilação (hipercapnia)
```

### 📋 Tabela de Manejo Rápido:

| Complicação | Sinais de Alerta | Conduta Imediata |
|-------------|-----------------|-----------------|
| **Hipoxemia** | SpO₂ <85%, cianose | ↑ FiO₂, pausa no procedimento, ventilar com AMBU |
| **Sangramento leve** | Sangue no aspirado, sem instabilidade | Aspirar, instilar adrenalina 1:10.000 gelada, posicionar lado afetado para baixo |
| **Sangramento grave** 🚨 | Hemoptise maciça, instabilidade | Balão de tamponamento, intubação seletiva, embolização/CT |
| **Pneumotórax** | Dor torácica súbita, ↑ pressão de pico, dessaturação | RX tórax urgente, drenagem se sintomático ou >20% |
| **Broncoespasmo** | Sibilos, ↑ resistência, ↑ pressão de pico | Broncodilatador inalatório/IV, ↑ sedação, pausa |
| **Arritmia** | Alteração no ECG, hipotensão | Parar procedimento, corrigir hipoxemia, ACLS se necessário |

> 📊 **Taxas reais**: Em série de 1.949 procedimentos, eventos adversos leves em 7,2%, graves em 0,5% (pneumotórax 0,4%, hemorragia fatal 0,1%) [[4]] DOI: 10.31744/einstein_journal/2018AO4380

## 🔄 ALGORITMO DECISÓRAL RÁPIDO: "Devo fazer broncoscopia agora?"

```
1️⃣ Pergunta chave: "O resultado vai mudar a conduta?"
   ↓ NÃO → ADIAR
   ↓ SIM → Continuar

2️⃣ O paciente está oxigenável? (SpO₂ ≥90% com suporte atual)
   ↓ NÃO → Otimizar ventilação primeiro
   ↓ SIM → Continuar

3️⃣ Há contraindicação absoluta?
   ↓ SIM → ADIAR/CONTRAINDICADO
   ↓ NÃO → Continuar

4️⃣ Equipe/equipamento adequado?
   ↓ NÃO → Transferir ou adiar
   ↓ SIM → PROCEDER com monitorização intensiva
```

## 💡 DICAS DE OURO PARA MEMORIZAÇÃO

### Mnemônico Final: **BRONCO-UTI**
```
B - Benefício claro antes de iniciar
R - Revisar contraindicações (NÃO-FAÇA)
O - Oxigenar bem antes (FiO₂ 100%)
N - Não esquecer: calibre cânula vs. broncoscópio
C - Complicações: conhecer HIPO-BRA-SP
O - Observar pós-procedimento (RX se biópsia)

U - UTI exige monitorização contínua (ECG, SpO₂, PA)
T - Toalete brônquica: indicação frequente e válida
I - Informar família e documentar consentimento
```

### Regra 3-30-3 para Segurança:
- **3 minutos**: Pré-oxigenação com FiO₂ 100%
- **30 segundos**: Pausa para reavaliar se SpO₂ cair <85%
- **3 horas**: Observação pós-procedimento com biópsia (RX tórax se sintomas)
