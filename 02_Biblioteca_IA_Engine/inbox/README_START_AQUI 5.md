# TEMI 2027 — Vault de Preparação Máxima 🧠🔥

**Alvo operacional:** prova TEMI no final de 2027.  
**Início sugerido:** 20/04/2026.  
**Horizonte aproximado:** 81.3 semanas até meados de novembro de 2027.  
**Premissa:** como o edital de 2027 ainda pode mudar, este plano foi estruturado com base no edital TEMI 2026 e deve ser recalibrado quando o edital 2027 for publicado.

## Como usar este vault no Obsidian

1. Abra esta pasta como vault.
2. Comece pelo arquivo `00_Dashboard_TEMI_2027.md`.
3. Use `02_Ciclo_Diario_Plantao_TDAH.md` todos os dias.
4. Use o CSV `anki/TEMI_2027_Anki_Seed.csv` para importar flashcards iniciais no Anki.
5. Todo caso de UTI, questão errada, ECG, ventilador ou USG deve virar **1 nota + 1 pergunta + 1 flashcard**.

## Filosofia do plano

Você não está estudando para “passar”.  
Você está treinando para responder como intensivista seguro, claro, objetivo e avaliável em prova teórica e prática.

**Meta de excelência:**
- Teórica: estabilizar > 75/90 em simulados próprios e > 80/90 na reta final.
- Prática: responder no padrão **Nível 5**: segurança, priorização, fisiologia, conduta, reavaliação, comunicação e equipe.
- Trilha prática: ECG diário, VMI semanal profunda, POCUS com log de imagens e mentoria.
- IA: usar como tutor, examinador, revisor, gerador de questões e auditor de raciocínio — nunca como fonte única.
