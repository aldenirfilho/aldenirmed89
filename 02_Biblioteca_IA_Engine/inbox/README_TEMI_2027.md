# TEMI 2027 - Central de Preparação

Este vault foi desenhado para funcionar como um sistema vivo de estudo para o TEMI 2027: leitura, questões, resumos, cards, algoritmos, prova prática, atualizações, dúvidas de plantão e auditoria de respostas por IA.

## Fluxo mínimo diário

1. Capturar: dúvida, questão errada, imagem, ECG, curva de VM ou conduta que gerou insegurança.
2. Classificar: tema, fonte, nível de urgência e pasta correta.
3. Transformar: resumo de 1 página, card ou algoritmo.
4. Testar: questões, caso oral ou estação prática.
5. Revisar: 24 h, 7 d, 30 d, 90 d.
6. Consolidar: mover para `Respostas_Aprovadas`, `Algoritmos` ou `High_Yield_100`.

## Regra de ouro

Nenhum conteúdo entra no acervo definitivo sem fonte, data, tema, síntese e próxima revisão.
