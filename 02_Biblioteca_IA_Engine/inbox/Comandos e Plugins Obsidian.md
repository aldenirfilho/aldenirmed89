## 🧩 Como abrir uma nota do lado da outra no Obsidian

## Jeito 1 — pelo mouse ✅

1. Abra uma nota qualquer.
2. No topo da nota, clique nos **três pontinhos `...`**.
3. Escolha:
```
Split right
```

ou em português:

```
Dividir à direita
```

Pronto: a nota abre em **duas colunas lado a lado**.

---

## ⌨️ Jeito 2 — pelo teclado / Command Palette

No Mac:

```
Cmd + P
```

Depois digite:

```
split right
```

ou:

```
dividir à direita
```

Selecione o comando.

---

## 🖱️ Jeito 3 — arrastando a aba

1. Abra duas notas.
2. Clique e segure na **aba da nota** no topo.
3. Arraste para o lado direito da tela do Obsidian.
4. Solte quando aparecer uma área sombreada.

Isso cria uma divisão lateral.
