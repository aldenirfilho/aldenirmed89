# 🧠 EIXO 5 — EMERGÊNCIAS NEUROLÓGICAS E NEUROINTENSIVISMO
**Conexões:** [[HUB-PRINCIPAL]] | [[ONSD-PIC]] | [[Escalas-Scores]]

## ⭐ PONTOS MAIS COBRADOS
> [!tip]
> 1. **AVC isquêmico** — tPA janela 4,5h, trombectomia DAWN/DEFUSE-3, Guideline AHA 2026
> 2. **Hemorragia subaracnóidea** — Hunt-Hess, nimodipino, coiling vs clipping
> 3. **TCE grave** — Monroe-Kellie, manitol vs soro hipertônico, PPC ≥60
> 4. **Morte encefálica** — CFM 2.294/2021, protocolo, doação
> 5. **ONSD** — Ponto de corte 5.8mm, Sn 90% Sp 85% (→ [[ONSD-PIC]])

## 📊 Números Obrigatórios
| Conceito | Valor |
|----------|-------|
| tPA AVC janela | **4,5h** (NINDS / ECASS III) |
| tPA dose | **0,9 mg/kg** (máx 90mg), 10% bolus |
| PA alvo antes tPA | < **185/110** mmHg |
| Trombectomia janela estendida | **24h** (DAWN) |
| PPC alvo TCE grave | ≥ **60 mmHg** |
| Manitol dose | **0,5-1 g/kg** IV |
| ONSD alarme | > **5,8 mm** |
| Morte encefálica avaliadores | **2 médicos distintos** + intervalo por idade |
