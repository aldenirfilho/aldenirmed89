# 🫁 BLUE PROTOCOL — Diagnóstico Diferencial de IRA Aguda

**Conexões:** [[POCUS-HUB]] | [[E2-Monitoracao-Suporte]] | [[E4-Insuficiencias-Organicas]] | [[LUS-Score]] | [[PTX-USG]] | [[Derrame-Pleural]] | [[TVP-VCI]]

> [!info] Trial de Referência
> **Lichtenstein DA & Mezière GA.** Relevance of lung ultrasound in the diagnosis of acute respiratory failure. *Chest.* **2008;134(1):117-125.**
> N=260 pacientes UTI Paris | **Acurácia global: 90,5%**

---

## 🗺️ ARTEFATOS — FUNDAMENTOS

### Linha A
- Horizontal, equidistante da pleura
- **= Normal OU PTX** (diferenciar pelo lung sliding)
- Artefato de reverberação da interface parietal

### Linha B (Comet tail / Rocket Sign)
- **Vertical**, nasce na pleura, alcança o fundo
- Hiperecoica, apaga linhas A
- **≥3 por espaço intercostal = PATOLÓGICO**
- Causa: espessamento septal intersticial (EAP, SDRA, pneumonia, fibrose)

### Lung Sliding
- Deslizamento pleural: pulmão aerado em movimento
- **Presente → Exclui PTX local** (Sn 95%, Sp 94%)
- **Ausente → PTX ou pleurodese/intubação seletiva**
- Modo M: [[Seashore Sign]] = normal | [[Barcode Sign]] = PTX

### Lung Point
- Transição seashore↔barcode no Modo M
- **PATOGNOMÔNICO de PTX** (Sp 100%)
- Localiza extensão do PTX

## 📊 PERFIS DO BLUE PROTOCOL

> [!success] PERFIL A — Linhas A + Lung Sliding bilateral
> - **+ TVP presente** (compressão femoral/poplítea) → **TEP** (VPP 81%)
> - **+ TVP ausente** → **DPOC exacerbação** ou **Asma** (Sn 89%)
> 
> ⚠️ Sempre checar veias femorais se Perfil A + dispneia aguda!

> [!danger] PERFIL B — ≥3 Linhas B bilaterais anteriores difusas
> → **Edema Agudo de Pulmão** (Sn **97%**, Sp **97%**)
> 
> Diferencial: EAP vs SDRA → LUS Score + contexto clínico

> [!warning] PERFIL A/B — Linhas A de um lado + Linhas B contralateral
> → **Pneumonia unilateral** (Sp **100%**)

> [!note] PERFIL B' — Linhas B bilaterais + AUSÊNCIA lung sliding
> → **Pneumonia** (sliding abolido por consolidação subpleural)

> [!note] PERFIL C — Consolidação anterior (com ou sem broncograma)
> → **Pneumonia**
> 
> Broncograma aéreo **dinâmico** = pneumonia (≠ atelectasia estática)

> [!note] PERFIL A + PLAPS
> PLAPS = Posterior-Lateral Alveolar/Pleural Syndrome
> → **Pneumonia + Derrame pleural parapneumônico**

> [!danger] PERFIL A + Ausência sliding + Sem PLAPS
> → **Pneumotórax** → confirmar com [[Lung Point]]

## 🔄 ALGORITMO BLUE — FLUXOGRAMA

```
DISPNEIA AGUDA
     │
     ▼
Avaliar 4 zonas/hemitórax
     │
     ├─ B-lines bilaterais? → PERFIL B → EAP ✓
     │
     ├─ Linhas A bilaterais?
     │      │
     │      ├─ TVP presente? → PERFIL A + TVP → TEP
     │      └─ TVP ausente? → DPOC / Asma
     │
     ├─ A unilateral + B contralateral? → PERFIL A/B → PNEUMONIA
     │
     ├─ B bilaterais + sem sliding? → PERFIL B' → PNEUMONIA
     │
     ├─ Consolidação anterior? → PERFIL C → PNEUMONIA
     │
     └─ Linhas A + sem sliding + sem PLAPS? → PTX → Lung Point
```
