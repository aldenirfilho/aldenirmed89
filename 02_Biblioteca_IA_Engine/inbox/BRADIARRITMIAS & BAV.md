## ⚡ ALGORITMO RÁPIDO ACLS 2025 🔄

```
FC <50 bpm + SINAIS DE INSTABILIDADE? 
│
├─❌ NÃO → Monitorizar + Investigar causa (H's e T's) 👁️
│
└─✅ SIM → ATROPINA 1mg IV bolus 🎯
           │
           ├─✅ MELHOROU? → Manter + Investigar causa raiz 🔍
           │
           └─❌ PERSISTE? → ⚡ MARCAPASSO EXTERNO (TCP) 
                          OU
                          💉 DOPAMINA 5-20 mcg/kg/min 
                          💉 EPINEFRINA 2-10 mcg/min
```

> 📌 **Regra de Ouro TEMI**: Atropina pode piorar BAV infra-nodal (QRS alargado) → Pular direto para TCP se QRS >120ms! [[19]]

---

## 📊 CLASSIFICAÇÃO BAV + INDICAÇÃO DE PACING

| Tipo BAV | ECG | Estável? | Ação Imediata | TEMI Pearl 🎓 |
|----------|-----|----------|---------------|---------------|
| **1º Grau** | PR >200ms | ✅ Sempre | Observar | Nunca indica pacing isolado |
| **Mobitz I** | PR progressivo ↑, QRS narrow | ✅ Geralmente | Atropina se sintomático | Bloqueio nodal → Atropina pode funcionar |
| **Mobitz II** | PR fixo, QRS escape largo | ❌ Instável | ⚡ TCP IMEDIATO | Bloqueio infra-nodal → Atropina INEFICAZ [[11]] |
| **BAV Total** | Dissociação AV, QRS escape | ❌ Emergência | ⚡ TCP + Preparar transvenoso | Escape juncional (40-60bpm) vs ventricular (<40bpm) = prognóstico |

> 🧠 **Mnemônico TDAH-Friendly**: **"MOB-II = MARCA-PASSO JÁ!"** ⚡

## ⚙️ PROTOCOLO TCP (TRANSCUTANEO) PASSO-A-PASSO

### 🎒 PREPARAÇÃO (30 segundos cronometrados ⏱️)
1. **Skin prep**: Raspar pelos + álcool 70% → melhor adesão [[45]]
2. **Posição pads**: 
   - **Antero-posterior** (preferencial): Anterior V3 + Posterior escápula esquerda
   - **Antero-lateral**: Paraesternal direito + ápice (V5-V6) [[45]]
3. **Conectar**: Pads → cabo pacing → monitor/desfibrilador
4. **Sedação PRN**: Fentanil 25-50mcg ou Midazolam 1-2mg IV (consciente) [[8]]

### ⚡ CONFIGURAÇÃO DO GERADOR
| Parâmetro | Setting Inicial | Ajuste | Meta |
|-----------|----------------|--------|------|
| **Modo** | DEMANDA (VVI) | - | Evitar competição com ritmo intrínseco |
| **Frequência** | 60-80 bpm | ↑ se hipotenso | Manter PAS >90mmHg |
| **Corrente (mA)** | 0 → ↑ 10mA em 10mA | Até CAPTURA ELÉTRICA | Espícula + QRS largo no ECG |
| **Sensibilidade** | Automático | Ajustar se undersensing | Triângulos no ECG sincronizados |

### ✅ CONFIRMAÇÃO DE CAPTURA (CRÍTICO!)
```
🔌 Captura Elétrica: Espícula seguida de QRS largo no monitor
💓 Captura Mecânica: 
   ├─ Palpar pulso central (carotídeo/femoral) sincronizado
   ├─ POCUS: contração ventricular visível
   └─ SpO2/arterial: onda de pulso sincronizada com pacing
```

> ⚠️ **Armadilha TEMI**: Captura elétrica ≠ captura mecânica! Sempre confirmar pulso/eco. [[45]]

## 💊 DOSES EMERGÊNCIA (CARD BOLSO)

| Droga | Dose | Via | Repetição | Máximo | Alerta TDAH 🎯 |
|-------|------|-----|-----------|--------|----------------|
| **Atropina** | 1 mg | IV bolus | 3-5 min | 3 mg | Ineficaz em BAV infra-nodal! |
| **Dopamina** | 5 mcg/kg/min | IV infusão | Titular | 20 mcg/kg/min | Extravasamento = necrose → acesso central ideal |
| **Epinefrina** | 2 mcg/min | IV infusão | Titular | 10 mcg/min | Taquicardia/Isquemia como efeitos adversos |
| **Adenosina** | 6 mg → 12 mg | IV push rápido | 1-2 min | - | Só para taquicardias regulares de QRS narrow! |

> 🧪 **Curiosidade Nerd**: A atropina age bloqueando receptores muscarínicos M2 no nó sinusal/AV → ↓ tônus vagal → ↑ FC. Mas em bloqueios infra-nodais (His-Purkinje), não há inervação parassimpática significativa → sem efeito! [[45]]

## 🎯 TEMI CORNER: 5 PEARLS QUE CAEM

1. **BAV 2:1** → Sempre tratar como Mobitz II até provar o contrário (risco de progressão para BAVT)
2. **Bradicardia + IAM inferior** → Frequentemente vagal → Atropina tem maior chance de sucesso
3. **Pacing transcutâneo doloroso** → Sedação não é opcional em paciente consciente (ética + eficácia)
4. **Hipercalemia** → Pode mimetizar BAV + alargamento QRS → Tratar K+ antes de pacing se possível
5. **Pacing "rate-drop response"** → Indicação Classe IIb para síncope vasovagal cardioinibitória >40 anos com assistolia documentada [[33]]

## 🧩 CHECKLIST EXECUÇÃO RÁPIDA (TDAH-OPTIMIZED)

```
[ ] 1. Reconhecer instabilidade: PAS<90, AMS, shock, dor isquêmica, IC aguda
[ ] 2. Atropina 1mg (se QRS narrow e suspeita nodal)
[ ] 3. Preparar TCP enquanto espera resposta (multitarefa estratégica!)
[ ] 4. Pads: pele seca + sem pelos + posição correta
[ ] 5. Modo DEMANDA, FC 70, corrente 0
[ ] 6. ↑ corrente até captura elétrica (ECG) + mecânica (pulso/eco)
[ ] 7. Sedar se consciente (fentanil/midazolam)
[ ] 8. Documentar: ritmo pré, settings, captura, resposta hemodinâmica
[ ] 9. Acionar cardiologia/HEMODINÂMICA para pacing transvenoso definitivo
```
