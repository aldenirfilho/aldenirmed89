# 🧠 ONSD — Diâmetro da Bainha do Nervo Óptico / PIC

**Conexões:** [[POCUS-HUB]] | [[E5-Neurointensivismo]] | [[T-Dubourg2011]]

> [!info] Trial de Referência
> **Dubourg et al., Intensive Care Med 2011** — Meta-análise
> Sn **90%**, Sp **85%** para PIC >20 mmHg

---

## 🔬 TÉCNICA

| Etapa | Detalhe |
|-------|---------|
| Sonda | Linear 7-15 MHz |
| Posição | Gel sobre **pálpebra fechada** (SEM pressão excessiva) |
| Vista | Axial — nervo óptico hipoecoico posterior ao globo |
| Ponto de medida | **3 mm posterior ao globo** (eixo transverso) |
| Nº medidas | 3 por olho → **média bilateral** |
| Normal adulto | ≤ **5.0 mm** |
| Alarme | > **5.8 mm** → PIC provável >20 mmHg |
| Zona cinza | 5.0–5.8 mm → avaliar contexto |

---

## ⚡ ALGORITMO PIC ELEVADA

```
ONSD > 5.8mm (média bilateral)
         │
         ▼
  PIC provável > 20 mmHg
         │
    ┌────┴─────────────────┐
    │                       │
Medidas imediatas        TC urgente
• Cabeceira 30°          + Neurocirurgia
• Manitol 1g/kg IV       
• NaCl 3% 250mL IV       PL CONTRAINDICADA
• Normocapnia (PaCO₂ 35-38)
```

> [!danger] CONTRAINDICAÇÕES
> Trauma ocular / perfuração / suspeita de globo aberto — NÃO REALIZAR

---

## 💡 Pontos de Prova TEMI

> [!tip] Números obrigatórios
> - Ponto de corte: **5.8 mm** (3mm posterior ao globo)
> - Sn **90%**, Sp **85%** (Dubourg ICM 2011)
> - Realizar **bilateral** e calcular **média**
> - PL **CONTRAINDICADA** se ONSD >5.8mm
