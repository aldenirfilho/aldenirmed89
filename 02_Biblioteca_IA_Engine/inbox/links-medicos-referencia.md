## 🧠 MAPA RÁPIDO DE DECISÃO

```
Dúvida clínica aguda no plantão?
├── 1º → UpToDate ou MDCalc
├── 2º → TRIP Database (guideline rápida)
└── 3º → EMCrit/IBCC (manejo prático UTI)

Precisa de evidência para discussão?
├── 1º → PubMed Clinical Queries (RCT)
├── 2º → The Bottom Line (resumo do trial)
└── 3º → Cochrane (revisão sistemática)

Atualização semanal de UTI?
├── → Critical Care Reviews
├── → ICMWK
└── → St. Emlyn's

Dúvida sobre POCUS na beira-leito?
├── Internacional → EMCrit POCUS + LITFL + 5MinSono
└── Nacional → CETRUS + Afya POCUS + Bárbara Valente

Preparo para TEMI?
├── → Medway + Afya Portal
├── → The Bottom Line (trials cobrados)
└── → AMIB (diretrizes nacionais)
```
