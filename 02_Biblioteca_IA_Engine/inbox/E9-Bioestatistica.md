## 📊 Fórmulas Essenciais
| Conceito | Fórmula |
|----------|---------|
| Sensibilidade | VP / (VP + FN) |
| Especificidade | VN / (VN + FP) |
| VPP | VP / (VP + FP) |
| VPN | VN / (VN + FN) |
| RR | (a/a+b) / (c/c+d) |
| OR | (a×d) / (b×c) |
| NNT | 1 / Redução Risco Absoluto |
| AUC-ROC | 0.5 = acaso, 1.0 = perfeito |
| I² heterogen. | <25% baixa, 25-75% mod, >75% alta |
