## 🧩 Como abrir uma nota do lado da outra no Obsidian

## Jeito 1 — pelo mouse ✅

1. Abra uma nota qualquer.
2. No topo da nota, clique nos **três pontinhos `...`**.
3. Escolha:
```
Split right
```

ou em português:

```
Dividir à direita
```

Pronto: a nota abre em **duas colunas lado a lado**.

---

## ⌨️ Jeito 2 — pelo teclado / Command Palette

No Mac:

```
Cmd + P
```

Depois digite:

```
split right
```

ou:

```
dividir à direita
```

Selecione o comando.

---

## 🖱️ Jeito 3 — arrastando a aba

1. Abra duas notas.
2. Clique e segure na **aba da nota** no topo.
3. Arraste para o lado direito da tela do Obsidian.
4. Solte quando aparecer uma área sombreada.

Isso cria uma divisão lateral.

---

## 🎥 Como ver vídeos no Obsidian

Você tem **4 jeitos principais**, do mais simples ao mais avançado:

---

## 1) Ver vídeo do YouTube dentro da nota

Cole o link do YouTube com `![]()`:

```markdown
![](https://www.youtube.com/watch?v=ID_DO_VIDEO)
```

Exemplo:

```markdown
![](https://www.youtube.com/watch?v=dQw4w9WgXcQ)
```

Isso pode incorporar o vídeo diretamente dentro da nota, quando o YouTube permite embed. Alguns vídeos podem aparecer como indisponíveis porque o próprio site ou o dono do vídeo bloqueia incorporação. Fóruns do Obsidian registram esse comportamento com YouTube, inclusive erros de embed em alguns casos.

---

## 2) Usar iframe — jeito mais controlado

Para YouTube, clique em:

```
Compartilhar → Incorporar
```

Copie o link embed e coloque assim no Obsidian:

```html
<iframe width="560" height="315"
src="https://www.youtube.com/embed/ID_DO_VIDEO"
title="YouTube video player"
frameborder="0"
allowfullscreen>
</iframe>
```

A documentação oficial do Obsidian mostra que páginas web podem ser incorporadas usando `iframe`, mas alerta que alguns sites não permitem incorporação e exigem URLs próprias de embed.

---

## 3) Ver vídeo salvo no próprio Vault

Se você tem um vídeo no computador, coloque o arquivo dentro da pasta do seu vault, por exemplo:

```
Anexos/Videos/aula-ventilacao-mecanica.mp4
```

Depois, dentro da nota:

```markdown
![[aula-ventilacao-mecanica.mp4]]
```

Ou:

```markdown
![[Anexos/Videos/aula-ventilacao-mecanica.mp4]]
```

Isso embute o vídeo localmente na nota. O Obsidian usa `!` antes de links internos para incorporar arquivos do vault.

⚠️ **Cuidado:** vídeos grandes podem deixar o vault pesado e atrapalhar sincronização pelo iCloud/Obsidian Sync.

---

## 4) Usar plugin para assistir e anotar vídeos

Para estudo médico/TEMI, o melhor é usar plugin com **timestamps**.

### Plugins úteis

| Plugin | Para que serve |
| --- | --- |
| **Media Extended** | Melhor controle de áudio/vídeo no Obsidian |
| **Timestamp Notes** | Anotar vídeos com timestamps clicáveis |
| **YouTube Iframe Timestamps** | Incorporar YouTube com timestamps na nota |
| **Surfing** | Abrir páginas/vídeos dentro do Obsidian como navegador interno |

O plugin **Timestamp Notes** foi criado justamente para fazer anotações lado a lado com vídeos e usar timestamps para controlar o vídeo.  
O **YouTube Iframe Timestamps** permite incorporar vídeos do YouTube com timestamps diretamente nas notas.
