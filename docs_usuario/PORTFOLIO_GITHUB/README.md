Este índice reúne **26 repositórios públicos em 22/10/2026**, agrupados por finalidade, após percorrer o inventário até o fim. O inventário inicial de 24 passou a incluir o README de perfil e **Paradoxos Inexoráveis**. Os estágios descrevem a documentação disponível; funcionamento, revisão clínica e prontidão comercial têm verificação própria.

As cinco áreas temáticas e a seção de identidade abaixo facilitam a navegação pelo GitHub. As duas contagens representam coisas diferentes.

## Projetos relacionados

- **AldenirMed89 e Antigravity:** compartilham temas e histórico de educação médica. O portal AldenirMed89 é a entrada escolhida para este portfólio; os dois repositórios permanecem identificados separadamente.
- **RespiraCrit, RespiraCrit v2 e RespiraSense ICU:** pertencem ao eixo respiratório. As duas primeiras são interfaces web; RespiraSense tem código Python/Streamlit e execução local documentada.
- **360X Brasil:** os dois portais cívicos têm conteúdo e ciclos próprios. Os nomes técnicos legados foram mantidos nos links.
- **Atlas Vivo:** plantas, animais e rochas são distribuições distintas. Atualizações de conteúdo e integridade seguem a documentação de cada uma.
- **BLACKBLOK:** o título segue o conteúdo atual do README; o nome técnico do repositório ainda é `ORGANIZA-OCODIFICADATEOLOGICACRIST-`.
- **Auditoria Religiosa 360:** integra investigação documental, contraditório, transparência financeira, impacto social e uma arquitetura de agentes; não publica ranking automático de culpa.

## Participar e acompanhar

Abra o README do projeto para conhecer seu escopo, forma de execução, referências e limitações. Melhorias de documentação, acessibilidade, organização e revisão especializada são formas úteis de colaboração.

**Projetos médicos:** finalidade educacional; cada ferramenta informa suas condições de revisão e validação. **Projetos culturais:** obras e marcas de terceiros mantêm seus respectivos direitos. A disponibilidade pública de um repositório não substitui uma licença de uso.
