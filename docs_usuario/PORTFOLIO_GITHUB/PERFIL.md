## 🛠️ Como desenvolvo os projetos

- **Conhecimento organizado:** fontes, objetivos e limites descritos na documentação.
- **Leitura acessível:** blocos curtos, hierarquia visual e caminhos claros para estudar ou explorar.
- **Desenvolvimento com IA:** criação assistida, revisão humana e melhorias graduais.
- **Tecnologia útil:** sites, aplicativos e materiais educacionais adequados ao objetivo de cada iniciativa.

Os projetos médicos têm finalidade educacional. A disponibilidade de um site ou do código não implica validação clínica; consulte o estado de revisão, as referências e os limites de cada recurso.
