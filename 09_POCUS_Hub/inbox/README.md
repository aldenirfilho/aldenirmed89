# Inbox — POCUS Hub

Coloque aqui aulas, vídeos, artigos, documentos, imagens, dicas, modelos de USG e materiais de estudo em POCUS.

Formatos aceitos: PDF, EPUB/MOBI/AZW3, DOC/DOCX/RTF/Pages, XLS/XLSX/Numbers, CSV/TSV, MD/Markdown, PPT/PPTX/Keynote, TXT/SRT/VTT, HTML/HTM, imagens, vídeos, áudio, APKG/Anki e compactados.

Links externos e páginas HTML interativas devem ser adicionados em `../links/links.json`.

Para atualizar o catálogo:

```bash
cd 09_POCUS_Hub
bash scan_inbox.sh
```
