# Links — POCUS Hub

Adicione links externos, páginas HTML interativas, aulas, vídeos, artigos online ou modelos de USG em `links.json`.

Exemplo:

```json
[
  {
    "title": "Nome do material",
    "url": "https://exemplo.com/pocus.html",
    "format": "html",
    "description": "Descrição objetiva do conteúdo.",
    "tags": ["pocus", "usg", "html"]
  }
]
```

Depois rode `bash scan_inbox.sh` na pasta do módulo.
